# P3 验证报告 · UI 最小闭环（5 件套）

> **对应票**：`P3-T1`（壳）· `P3-T2`（播放/暂停 · 时间 · 进度条+拖拽）· `P3-T3`（全屏与旋转 · 字幕开关占位）· `P3-T4`（文件选择）
> **日期**：2026-10-13
> **判定门**：`G3` —— **模拟器上能选文件、能播、能拖进度、能全屏**
> **结论**：**达成**（5 条 UI 自动化全过，已固化进门禁 `[7/8]`）。⚠️ `M3` 尚未达成，见 §四。

---

## 一、五件套落点

| # | 件 | 落在哪 | 可测部分 |
| --- | --- | --- | --- |
| 壳 | 播放器界面 | `PlayerScreenView` / `PlayerSurfaceView` / `PlayerViewModel` | `progress`（含 NaN 守卫）· `aspectRatio`（含 16:9 兜底） |
| ① | 播放/暂停 | `PlayerControlBar` → `PlayerViewModel.togglePlayPause()` | `isPlaying` 口径；**`idle → playing` 非法**（不允许没文件就播） |
| ② | 时间显示 | `PlayerControlBar.clock` | `mm:ss` / `h:mm:ss`；负数、NaN、∞ 一律 `0:00`；**取整不四舍五入** |
| ③ | 进度条 + 拖拽 | `PlayerScrubModel` + `PlayerSlider` | 比例钳制；**没按下不发 seek**；松手只发一次；按下先暂停 |
| ④ | 全屏与旋转 | `PlayerFullscreenModel` | **宿主外壳让位**；**退出必须复位** |
| ⑤ | 字幕开关（占位） | `PlayerSubtitleToggle` | **开关 ≠ 生效**：`isEnabled` 与 `hasSource` 分开 |
| — | 文件选择 | `fileImporter` + `PlayerSecurityScopedAccess` | 访问权记账：换文件才释放；重复 begin 不重复 start |

## 二、`G3` 判定（`gate.sh` 的 `[7/8]`，真点一遍）

| 判定项 | 结果 | 证据 |
| --- | --- | --- |
| 能播 | ✅ | 状态行出现 `playing` + `640×360` + `输出 44100 Hz` |
| 能暂停 | ✅ | 点一下 → `paused`；再点 → 脱离 `paused` |
| 能拖进度 | ✅ | 拖到 95% 读数离开 `0:00`；拖到 5% 回到 `0:00` |
| 能全屏 | ✅ | 全屏后宿主按钮**不再可点**；退出后回来 |
| 能选文件 | ◑ | **系统选择器确实被拉起并接管界面**（宿主按钮不再可点）；⚠️ **没证到"在选择器里选中某个文件并播起来"** |

> ⚠️ **"能选文件"这项要如实说**：跨进程驱动"文件" App 在 CI 上极不稳，本轮只证到"选择器被拉起"。
> **补法**：真机手动选一次（顺带也是 `M3` 的真机校准内容）。

### 一处刻意的例外：UI 测试用 XCTest

`Demo/UITests/G3UITests.swift` **刻意使用 XCTest** —— UI 自动化需要 `XCUIApplication`，
而 **Swift Testing 没有等价能力**。这不是"忘了迁移"，是工具能力的边界。
其余全部测试（根包 + MPV 包）一律 Swift Testing，这条例外已写在文件头注释里，避免日后被当违规清理。

## 五、过程中抓到的「断言盲」（都是变异测试抓的，不是猜的）

三次同一种错：**用例只覆盖了守卫为真的一侧，另一侧从未被执行**。

| # | 位置 | 缺口 | 补法 |
| --- | --- | --- | --- |
| 1 | `progress` | 原用例 `duration = 0` 被 `duration > 0` 短路，`isFinite` 从未执行 | 用「时长已知 + currentTime = NaN」 |
| 2 | `displayProgress` | 只断言"拖拽中"，把 `isScrubbing` 判断删掉照样绿 | 补「松手后必须回到真实进度」 |
| 3 | `fileAccess.begin` | 只测了类型本身，**没断言 view model 真的调了它** | 开只读窗口 `accessedFileURL` + 用例 |

> 结论：**变异体存活几乎总是"测试的盲区"，而不是"实现的错误"**；先怀疑测试。
