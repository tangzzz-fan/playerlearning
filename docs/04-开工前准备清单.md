## 一、「开工」的定义（准入条件）

`docs/03` 立的原则不变：**G0 通过之前，不写任何要长期留存的播放器代码。**

G0 已被本次拍板**升级**：

| 版本 | 判定门 |
| --- | --- |
| 原 G0 | `kingslay/FFmpegKit` 是否提供 iOS 真机 slice + 冒烟通过 |
| **现 G0** | **自建的动态 LGPL libmpv 产物**能在 iOS 真机跑起来（含 MoltenVK）+ 合规基线成立 |

原因：现成产物全部错配 —— FFmpegKit 是动态但 GPL，MPVKit 是 LGPL 但**静态**（静态无法满足 LGPL 的 re-linking 前提）。

**两条使用注意：**

1. **`python3` 必须显式指向 `/opt/homebrew/bin/python3`** —— PATH 里默认命中的仍是 WorkBuddy 托管版（`~/.workbuddy/binaries/python/...`）。那是隔离运行时，会随 WorkBuddy 升级漂移，而 LGPL 要求构建**可原样重跑**。
2. **GNU libtool 的命令带 `g` 前缀**（`glibtool` / `glibtoolize`）—— Homebrew 的标准行为。autotools 类库构建若报找不到 `libtoolize`，需把 gnubin 加入 PATH：
   ```bash
   export PATH="/opt/homebrew/opt/libtool/libexec/gnubin:$PATH"
   ```

> **拆分依据**（2026-10-13 拍板选项 A）：`P0-T5` 原为一步做完，但读构建脚本后发现动态化是 **4 处结构性改动 + 2 个版本风险**，且「做完才知技术行不行」。故拆为「先技术、后构建」，把技术不确定性与构建不确定性解耦。
> **结果验证了拆分是对的**：`P0-T5a` 一次通过，技术问号清零 ⇒ `P0-T5b` 变成纯工程活，随后也一次通过。
> **`P0-T5b` 的实测修正**：原以为「动态化 1 处 + 去掉 `--enable-version3` 1 处」即可。实测发现**「压回 LGPL-2.1」的真正门槛是依赖链而非开关** —— `--enable-gnutls` → `nettle` → `gmp` 三者同为 LGPLv3+，被链进来就必然要求 v3（FFmpeg 的 configure 直接报错拒绝）。**解法是把 TLS 后端换成 Apple 系统 SecureTransport**，从而整条 v3 链消失。详见 `docs/07` §3.2。

**新增施工硬约束（本次拍板产生）**

1. 产物**必须是动态 framework**（LGPL 的 re-linking 前提）。
2. 构建**必须脚本化、可原样重跑**，并归档 meson/configure 行 —— 不得依赖手工操作。
3. `docs/01` 允许借用的只有**设计思想与抽象**，**不得复制 KSPlayer 代码文本**（A1 反转后此条生效）。

### D2 的连带含义（已定，此处只作知情记录）

用公司号上架 ⇒

1. **App Store 的销售方名称 = 公司**（TIANJU DIHE (SUZHOU) DATA CO., LTD.），不是个人
2. **LGPL 合规责任人 = 公司** —— 包括 `§7-R1` 那条「尽力合规 + 灰区」的风险，由公司承担
3. 该 App 成为**公司资产**（与个人项目资产分离）
4. 需确认 App Store Connect 中该团队（`3GMJYX32U9`）具备创建 App 与提交审核的角色权限

### D3 的修正依据

`P0-T4` 从产物二进制的 configure 行里捞出 **`--enable-version3`** ⇒ MPVKit 的产物落在 **LGPLv3**（FFmpeg 官方对 `--enable-version3` 的定义即「upgrade (L)GPL to version 3」），与其 `LICENSE` 声明一致。

**但这同时给出一条更好的路**：`--enable-version3` 是**构建方的选择**。LGPL-2.1-or-later 的代码允许分发者选 v3，**也可以不选**。
⇒ 我们自建时不传该 flag，全链即可停在 **LGPL-2.1**，绕开 LGPLv3 §4(e)（挂钩 GPLv3 §6 的 Installation Information）—— iOS 上最拧巴的那条。

**推荐因此从"声明层面按 2.1"升级为"把 2.1 做成技术事实"。** 详见 [`05-libmpv产物实测报告.md`](05-libmpv产物实测报告.md) §2 发现 1。
