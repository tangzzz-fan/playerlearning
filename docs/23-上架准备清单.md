## 二、已落地（都能当场复核）

### 2.1 身份与版本

| 项 | 值 | 落在哪 |
| --- | --- | --- |
| `CFBundleDisplayName` | `PlayerStack` | `Demo/project.yml` → 生成的 `Info.plist` |
| `PRODUCT_BUNDLE_IDENTIFIER` | `com.playerstack.app` | 同上（**首传后不可改**，所以现在就定死） |
| `MARKETING_VERSION` | `1.0.0` | 同上 |
| `CURRENT_PROJECT_VERSION` | `1` | 同上（每次上传必须递增） |
| `TARGETED_DEVICE_FAMILY` | `1`（**仅 iPhone**） | 声明 iPad 会要求 iPad 截图 + iPad 上要说得过去，而我们**从未验证过 iPad 布局**；改回 `"1,2"` 是一行的事，但要先补验证 |
| `ITSAppUsesNonExemptEncryption` | `false` | 免掉每次上传手工回答"是否使用加密"（答错要被追材料） |

> **版本号只有一个源**：`Info.plist` 里写的是 `$(MARKETING_VERSION)` / `$(CURRENT_PROJECT_VERSION)`。
> 以前它是写死字面量（`1.0` / `1`）—— 那是"改了一处、另一处没改"的经典入口（`P-085` 同族）。

### 2.2 图标

- 路径：`Demo/Sources/Assets.xcassets/AppIcon.appiconset/AppIcon-1024.png`
- 1024×1024 · **`hasAlpha: no`**（App Store 会因为图标带 alpha 直接拒）
- 构图：深底 + 白色播放三角 —— 与控制条的暗底同一套颜色，**没有文字**（图标里的字在小尺寸下必糊）
- 验证：`sips -g pixelWidth -g pixelHeight -g hasAlpha <png>`

### 2.3 隐私清单（`Demo/Sources/PrivacyInfo.xcprivacy`）

**不采集**任何数据、**不跟踪**（`NSPrivacyCollectedDataTypes` 为空数组、`NSPrivacyTracking` 为 `false`、
无跟踪域）—— 依据是产品事实：无账号、无遥测、无广告 SDK、无自建服务端。

**Required Reason API 是量出来的，不是猜的**（同一个人产物、同一把尺子）：

```bash
B=MPV/Library/Libmpv.xcframework/ios-arm64/Libmpv.framework/Libmpv
nm -u "$B" | grep -E '(^|[[:space:]])(_stat|_fstat|_statvfs|_mach_absolute_time|_mach_continuous_time)(\$INODE64)?$' | sort | uniq -c
```

| 命中 | 归属类别 | 申报原因 |
| --- | --- | --- |
| `_stat` · `_fstat` | `FileTimestamp` | `C617.1`（容器内文件）· `3B52.1`（用户通过选择器选中的文件）—— 读媒体文件属性判断可否 seek / 缓存是否有效 |
| `_mach_absolute_time` · `_mach_continuous_time` | `SystemBootTime` | `35F9.1` —— 播放时钟走**单调时间**，改系统时间不会让音画跳变 |

**同一把尺子量过、确认不存在**：`_statvfs`（磁盘空间）、`_NSUserDefaults` / `_CFPreferencesCopyAppValue`
（偏好）⇒ 那两类**不申报，不是漏了**。

> ⚠️ 口径提醒（`P-082`）：`nm -u | grep -c _stat` 会连带命中 `_copyfile_state_alloc` 之类的**子串**。
> 必须**行尾锚定**，否则数字平白多出几条 —— 上面那条命令就是为了杜绝这件事。

## 三、打包步骤（命令，人工执行）

> 为什么不是脚本：验收标准是"能跑 + 测试通过"，不往仓库里堆门禁（董事长 2026-10-14 定的）。
> 下面是**人按需手动跑**的命令。

```bash
# 1) 归档（Release，自动签名；首次会去 Apple 拉描述文件 ⇒ 需要网络/代理）
cd Demo
xcodebuild archive \
  -project PlayerStackDemo.xcodeproj -scheme PlayerStackDemo \
  -configuration Release -destination 'generic/platform=iOS' \
  -archivePath /tmp/PlayerStack.xcarchive \
  -allowProvisioningUpdates \
  OTHER_SWIFT_FLAGS=-disable-sandbox

# 2) 导出成可上传的 ipa
xcodebuild -exportArchive \
  -archivePath /tmp/PlayerStack.xcarchive \
  -exportOptionsPlist ExportOptions.plist \
  -exportPath /tmp/PlayerStack-ipa \
  -allowProvisioningUpdates
```

- ⚠️ **`OTHER_SWIFT_FLAGS=-disable-sandbox` 不能省**：本机不带上它，SwiftUI 宏会报
  `StateMacro could not be found … malformed response`（本轮踩过一次，加上即过）。
  这只是**本机构建环境**的事，**不要写进工程文件**。
- 上传用 Xcode Organizer 或 Transporter（`altool` 已废弃，别照着老文章写命令）。
- 上传前确认 `CURRENT_PROJECT_VERSION` 已递增 —— **同一个 build 号不能被上传两次**。

## 四、只能人做的事（我做不到的部分）

| # | 事项 | 在哪做 | 为什么我做不了 |
| --- | --- | --- | --- |
| 1 | App Store Connect 账号协议（付费/免费 App 协议、税务） | App Store Connect | 涉及法人与银行信息 |
| 2 | 创建 App 记录（名称 / 主语言 / SKU / bundle id 绑定） | App Store Connect | bundle id 一旦绑定不可换 |
| 3 | **名称可用性**（App Store 重名检查） | App Store Connect | 名字在**全球榜单里唯一**，本机查不到 |
| 4 | **隐私政策 URL**（必需） | 自有网站 | 需要可公开访问的页面 |
| 5 | 分级问卷（年龄分级） | App Store Connect | 法律声明性质 |
| 6 | 截图（**6.9" iPhone**，如 1320×2868）+ 可选预览片 | 模拟器截或真机 | 需要**最终 UI 定稿**下的成品图 |
| 7 | 关键词 / 副标题 / 支持 URL | App Store Connect | 运营决策 |
| 8 | 分发证书与描述文件 | Apple Developer | 需要账号登录 |

**截图这件事的具体建议**：用 iPhone 16/17 Pro Max 模拟器 + 本项目的 `-directURL` 播一条真实片子，
在**控制条可见**的那一帧截（`LIVE` 徽标那张就是这么来的，见 `docs/22` §4.2）。

## 五、⚠️ 上架真正的门槛：LGPL 交付物（不是打包）

这条**跟审核无关，跟上架能否长期成立有关**。展开见 [`../ksplayer-playbook/D`](../ksplayer-playbook/D-产物与授权.md) §4 / §5 / §7，
这里只留**要交付什么**：

| 交付物 | 状态 | 说明 |
| --- | --- | --- |
| 库的**对应源码**（含我们打的补丁） | ⬜ 未整理 | 补丁在 `spike/p0-t5b-lgpl-dynamic-build/`；要连同**精确的构建配置**一起可复现 |
| 许可文本与说明（LGPL-2.1 + 上游 LICENSE） | ⬜ 未整理 | 商店页/网站要能访问 |
| "用户可替换库"的**尽力**说明 | ⬜ 未写 | iOS 上是灰区：App 被加密签名，用户拿不到可替换的那一份 |
| 修改声明 | ⬜ 未写 | 我们对上游做了哪些改动 |

> **对外表述纪律**（`D` §4）：只能宣称「**已尽力合规**」，**不得**宣称「已确保合规」。
> 真实风险来自**上游权利人投诉**，不是平台审核 —— 历史上有播放器这么下架的。

**另一件与开源许可无关、但商业分发要单独算的事**：**编解码专利池**（H.264 / HEVC）。
别把"我已经用 LGPL 了"当成"没有专利问题"—— 这是两码事（`D` §7）。
