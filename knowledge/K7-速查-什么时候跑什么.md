## 3 真机验证

```bash
UDID=<真机 UDID>; APP=<PlayerStackDemo.app 路径>
xcrun devicectl device install app --device $UDID "$APP"
xcrun devicectl device process launch --device $UDID --console --terminate-existing com.playerstack.demo -- <参数>
```

| 参数 | 用途 | 证据形式 |
| --- | --- | --- |
| `-directURL <url>` | 播任意 URL（本地 / HTTP / HLS / RTSP） | `[status]` 每秒一行 |
| `-autoLoadSample` | 自动加载样例（下载到容器再播**本地文件**） | 同 上 |
| `-headers "K: V,K2: V2"` | 注入自定义请求头 | 服务器侧 `--echo-headers` |
| `-exerciseTracks` | 多档枚举 + 切档（挂在 `-directURL` 上，多档只在 HLS 里） | `[tracks]` |
| `-exerciseControls` | 加载→播→停→再播 | `[exercise]` |
| `-exerciseFinish` | 播完→再点播放 | `[finish]` |
| `-soakRounds N` | 长跑稳定性 + 内存 | `[soak]` |
| `-traceUpdates` | ⚠️ 打开 mpv 内核日志 | **会把 console 在第 2 秒打爆**（`P-058`），长期观察别用 |

**起播分解**：每次 `load` 会打一行 `[startup]`（8 个节点，见 [`K3`](K3-运行面-一帧像素的旅程.md) §7）。

⚠️ **真机不能用 `127.0.0.1`** —— 手机在另一台设备上，服务器要 `--host 0.0.0.0`，URL 用**宿主局域网地址**。
⚠️ 局域网地址**要问路由表**（`route -n get default`），别写死 `en0`（`P-076`）。

## 4 网络取证（造环境）

```bash
# 静态服务器（支持 Range）—— 最常用
python3 Tools/serve-range.py --port 8765 --root <dir> --host 0.0.0.0

# 加开关造各种环境
… --throttle 45000              # 限速 45 KB/s（弱网）
… --stall-at 200000 --stall-for 5   # 发到第 N 字节后挂住 5 秒（造"缓冲→恢复"）
… --echo-headers                # 把收到的请求头打到 stderr（验请求头注入）
… --tls-cert a.crt --tls-key a.key  # 起 HTTPS（验证书校验）
```

| 我要造 | 做法 | 参考 |
| --- | --- | --- |
| 弱网点播 | `--throttle` | [`docs/12`](../docs/12-P5验证报告.md) |
| HLS 多码率（VOD） | `ffmpeg -var_stream_map …`（造法见 [`docs/14`](../docs/14-P5-T5-HLS多码率调研.md) §1.1） | `P5-T5` |
| HLS 直播 | 同上，但去掉 `hls_playlist_type vod`（改成滑窗） | [`docs/19`](../docs/19-P6-T5-HLS直播源.md) |
| RTSP 直播 | `mediamtx` + `ffmpeg -re -c copy -f rtsp rtsp://127.0.0.1:8554/live` | [`docs/16`](../docs/16-P6-T3-低延迟参数.md) |
| HTTPS（含"必须失败"的探针） | 自签 CA + `--tls-cert/--tls-key` | [`docs/20`](../docs/20-P0-T5d-HTTPS校验修复.md) |

⚠️ 本机跑本地服务要**清代理变量**（会话代理会劫持回环请求，`P-059`）：`env -u HTTP_PROXY -u HTTPS_PROXY curl …`

## 7 关键判据一览（"证明它真的生效"的手法）

| 要证明的事 | 手法 | 为什么不能偷懒 |
| --- | --- | --- |
| 补丁真的进了产物 | `nm -u` 查符号 | "我传了补丁" ≠ "它被应用了"（`P-079`） |
| 选项真的被接受 | 跑 `testEveryConfiguredOptionIsAcceptedByMPV` | "我设了" ≠ "它认了" |
| 证书校验真的生效 | **不受信任的证书必须失败** | 公网站点只能证"能播"（[`K5`](K5-网络面-直播与HTTPS.md) §6） |
| 某一层真的没参与 | 造一个**绕过它**的对照（如原生 ffmpeg 当客户端） | 否则归因不到（[`K5`](K5-网络面-直播与HTTPS.md) §5） |
| 跳过重建的库没变 | 逐字节指纹比对 | 省下的时间会以"产物不一致"还回来 |
| 推理是"真到过"而非"碰巧" | 找到能**两个来源写入**的那个状态（如 `pause`，`P-071`） | 时序挑一个的失败，也可能来自代码 |
